# custom cyphers

this is the part where i explain a bit about modifying the cypher! that way, if someone finds out about the program, they are STILL screwed, because now they STILL need to figure out the cypher you guys are using! :D

## custom cyphers, the idea
as previously mentioned, the IDs from the "bean" can be freely adjusted. all you need is a text file!

simply put, each line of the text file will be interpreted as a separate ID. so yes, this does mean you can make entire sentences within the cypher, and no one will be able to figure it out! this also allows for some ridiculous cypher machinations, where you also store dual letter things and what not... a mind bender for YOU to figure out! :D

### example text file:
```
A
B
C
D
beans
love
sexfm
dog
Q
Z
T
```
## custom cyphers, the addition
now that you have your text file, you need to add it. in the bean cypher settings, check the "custom cypher" option, and open through the file dialog the text file in question. the rest will be sorted!
