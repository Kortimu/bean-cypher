# E.D.G.E.
this will mansplain what "E.D.G.E.ing" means (hint: Enhanced Discord GIF Encryption)

so, as you may know, discord allows for markdown in the text.
want italics? use \**<- these puppers. ->*\*
want bold? use \*\***<- these bad boys! ->**\*\*
etc.

you can also make hyperlinks, by using the following syntax:
`[text](link)`

## ask yourself the following question: what happens when the link is a discord gif?
the gif displays, yet the contents of the text field disappear! because discord hides the message text when a gif is shown, the text field within the hyperlink is INVISIBLE! sorta. to see the message, you need to copy the text. neat nonetheless!

this in of itself is encryption, and this cypher supports it! just enable the E.D.G.E. setting, enter the link to the gif you want present, and DONE! enjoy :]
